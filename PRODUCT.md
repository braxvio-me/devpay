# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive (Expo / React Native, iOS + Android, web for preview)

## Users

- **Freelancers** in Ghana (developers, designers, writers, marketers) looking for milestone-based work, applying to jobs, delivering milestones, and withdrawing earnings to Mobile Money or bank.
- **Clients** (Ghanaian businesses and individuals) posting jobs, reviewing proposals, funding escrow, and releasing milestone payments.
- One account can switch between both roles (RoleContext).

## Product Purpose

DevPay Africa is an African-focused freelance marketplace: discovery, collaboration, escrow-protected milestone payments, and dispute resolution. Success is a freelancer getting paid safely and a client getting verified work delivered.

## Positioning

Escrow-first freelancing built for African payment rails: Mobile Money (MTN MoMo, Telecel Cash, AT Money), Ghana Card KYC, and GH₵ pricing from day one.

## Operating Context

- Day-1 market: Ghana. Currency GH₵ (GHS); locations such as Accra, Kumasi, East Legon.
- Payment rails: MoMo, local cards/bank via Ghana gateways (Paystack, Hubtel).
- Identity: Ghana Card verification ("Trusted" / verified badges).
- Architecture must stay multi-country / multi-currency ready.

## Capabilities and Constraints

- Screens: onboarding (splash, welcome, choose role, auth, OTP, profile setup, KYC), freelancer home, explore/search, job detail/apply/create/applicants, contracts and review, earnings, payment, withdraw, messages/chat, notifications, profile, settings, appearance, premium, logout, delete account.
- Light and dark mode both supported; user-selectable.
- Demo data is local and synthetic; no backend yet.

## Brand Commitments

- Name: DevPay (DevPay Africa).
- Visual reference is binding: the images in `ui/` (job-finder set by @siren.uix) define the layout, spacing, and look; `ui-design-spec.md` documents them. Content is adapted to DevPay Ghana, using fictional African client companies with monogram logos, not real-brand logos.
- Photos: free remote stock portraits, replaceable later.
